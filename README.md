# QR Code Museum Project

This project aims to improve the museum experience by integrating QR codes next to artworks.

Visitors can scan a QR code using their smartphone and instantly access a web page containing:

- Artwork descriptions
- Historical details
- Additional information

## Objective

To provide a more interactive, autonomous, and modern way to explore museums without relying entirely on guides.

## Benefits

- Self-paced visits
- Easy access to information
- Enhanced user experience
- Accessible anytime

## Technologies

- HTML
- CSS
- JavaScript
